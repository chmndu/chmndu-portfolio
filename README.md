# chmndu — Portfolio

Personal portfolio for **Chamindu Dahanayaka**, a frontend developer building digital products for the web.

## Tech

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Getting Started

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

Create a production build:

```bash
npm run build
```

Start the production server:

```bash
npm start
```
